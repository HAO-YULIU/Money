# 分帳工具 設計文件

日期：2026-11-18

## 目的

做一個類似 Lightsplit 的多人分帳網頁工具，用來記錄一群人的共同花費，算出每個人的餘額，並提供最少轉帳次數的結算建議。

## 目標

- 手機瀏覽器好用的分帳網頁，介面為繁體中文。
- 不用登入、不用伺服器，資料存在使用者自己的瀏覽器。
- 可以把目前的帳目變成一個網址分享給朋友查看。
- 部署在 GitHub Pages：`https://hao-yuliu.github.io/Money/`。

## 不做的事（第一版）

- 雲端同步、多人同時記帳。
- 登入或帳號。
- 外幣、匯率換算。
- LINE 機器人、AI 記帳。

## 失敗的情況（就算功能能跑也算失敗）

- 結算金額算錯或對不起來（所有人的餘額加總必須為 0）。
- 資料無預警消失。
- 在手機上很難操作。

## 考慮過的做法

| 做法 | 取捨 | 結果 |
|---|---|---|
| A. 純瀏覽器＋網址分享 | 最簡單、免伺服器；朋友只能看快照，不能一起記帳 | ✅ 使用者選擇 |
| B. 網頁＋Supabase 雲端資料庫 | 可多人同步記帳；要設定資料庫和權限 | 未採用，之後有需要再升級 |
| C. LINE 機器人 | 最像 Lightsplit；要 LINE 開發者帳號和伺服器，最複雜 | 未採用 |

使用者希望先用最簡單的方式，一個人負責記帳、其他人看結果就好。

## 使用者已決定的事

- 純瀏覽器，不用雲端資料庫。
- 不用登入。
- 部署在 GitHub Pages。

## 功能

### 1. 群組
- 可以建立多個群組（例如「日本旅遊」、「301 室友」），每個群組有名稱和成員名單。
- 可以新增成員和改名。已經有帳目的成員不能刪除。
- 首頁列出所有群組。

### 2. 記帳
- 每筆帳目包含：項目名稱、金額（新台幣，整數）、付款人、分攤成員、日期。
- 分攤方式：
  - **平分**：除不盡的零頭依序分給前面幾位成員，確保總和等於金額。
  - **各自金額**：輸入每人金額，總和必須等於帳目金額才能儲存。
- 可以編輯、刪除帳目。

### 3. 餘額
- 每位成員的餘額＝已付總額−應分攤總額。正數代表應收，負數代表應付。

### 4. 結算
- 用貪婪演算法產生轉帳建議：每次讓欠最多的人付給應收最多的人，轉帳次數接近最少。
- 可以把某一筆建議標記為「已還款」，系統會記成一筆還款紀錄，餘額跟著更新。

### 5. 分享（網址快照）
- 「分享」按鈕把整個群組的資料壓縮後放進網址的 `#` 後面，產生一個連結，可以複製後貼到 LINE。
- 朋友打開連結會看到唯讀的群組畫面（帳目、餘額、結算）。
- 唯讀畫面上有「存到我的瀏覽器」按鈕，可以把這個群組匯入朋友自己的瀏覽器，之後朋友可以自己記帳（但兩邊不會同步）。
- 匯入時如果已經有同一個群組，詢問要覆蓋還是另存一份。

### 6. 備份
- 因為清除瀏覽器資料會讓帳目消失，提供「匯出 JSON 檔」和「匯入 JSON 檔」功能。

## 技術做法

- **前端**：Vite + React + TypeScript，打包成純靜態檔案。
- **資料儲存**：瀏覽器 `localStorage`，存一份 JSON，包含版本號，方便以後改資料格式。
- **網址路由**：使用 `#` 路由（例如 `#/group/<id>`），因為 GitHub Pages 不支援單頁應用的網址改寫。
- **網址壓縮**：使用 `lz-string` 把 JSON 壓縮成可放進網址的字串。
- **部署**：GitHub Actions，push 到 `main` 時自動打包並發佈到 GitHub Pages。
- **測試**：Vitest，針對分帳計算、餘額、結算演算法、網址編碼與解碼寫單元測試。

- 平分時的零頭分配方式（依序分給前面幾位）。
- 加入 JSON 匯出匯入的備份功能。
- 朋友可以把分享的群組存到自己的瀏覽器。
- 版面以手機直式畫面為主。
