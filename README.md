# 分帳

簡單的多人分帳網頁：建立群組、記帳、看每個人應付應收多少，以及誰該轉給誰。資料存在你自己的瀏覽器。

網址：https://hao-yuliu.github.io/Money/

## 使用小提醒

- 固定用同一個瀏覽器開啟，最好「加到主畫面」。從 LINE 點開的連結會用 LINE 內建瀏覽器，資料和 Safari／Chrome 是分開的。
- 記得定期按「匯出備份」，換手機時在新手機「匯入備份」。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `程式/進入點.tsx` | 網頁啟動的地方 |
| `程式/計算/分攤.ts` | 每筆帳目每個人分攤多少（平分進位規則） |
| `程式/計算/餘額.ts` | 每個人總共應收或應付多少 |
| `程式/計算/結算.ts` | 誰該轉給誰多少 |
| `程式/計算/金額.ts` | 金額格式與輸入檢查 |
| `程式/計算/成員.ts` | 成員相關規則 |
| `程式/計算/資料型別.ts` | 資料格式定義 |
| `程式/儲存/本機儲存.ts` | 存取瀏覽器資料 |
| `程式/儲存/使用資料.ts` | 畫面讀寫資料的工具 |
| `程式/分享/連結編碼.ts` | 把群組壓縮進分享連結 |
| `程式/分享/備份.ts` | 匯出、匯入備份 |
| `程式/畫面/*.tsx` | 各個畫面（群組列表、群組頁、記帳表單、設定、分享） |
| `程式/畫面/樣式.css` | 外觀樣式 |
| `程式/測試/` | 測試設定與測試 |
| `文件/` | 設計文件與實作計畫 |

`*.test.ts(x)` 是對應功能的自動測試。`package.json`、`index.html`、`vite.config.ts`、`tsconfig.json`、`README.md`、`.github/` 是工具規定的檔名，不能改成中文。

## 本機開發

```bash
npm install
npm run dev     # 開發伺服器
npm test        # 執行測試
npm run build   # 打包到 dist/
```

## 部署

1. 到 GitHub repo 的 **Settings → Pages**，把 **Source** 設為 **GitHub Actions**（只需設定一次）。
2. 之後每次 push 到 `main`，GitHub Actions 會自動測試、打包並更新網站。
